# karpathy-guidelines (skill vendorizada)

> Fonte: `szkocot/andrej-karpathy-skills`. Instalar via `npx skills add https://github.com/szkocot/andrej-karpathy-skills --skill karpathy-guidelines`. Princípio central vendorizado aqui para consulta rápida sem precisar instalar.

## Alterações cirúrgicas

Toque apenas no que for necessário. Limpe apenas a sua própria sujeira.

Ao editar um código existente:
- Não tente "melhorar" o código, os comentários ou a formatação adjacentes.
- Não refatore o que não está quebrado.
- Adapte-se ao estilo existente, mesmo que você o fizesse de forma diferente.
- Se você notar código morto não relacionado, mencione-o — não o apague.

## Quando aplicar
Em toda edição de código já existente (ver tabela de "Roteamento automático" no `CLAUDE.md` — é aplicado automaticamente, sem precisar pedir).
