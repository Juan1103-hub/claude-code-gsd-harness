# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by
> gsd-ui-researcher, verified by gsd-ui-checker.

**Product DNA (from CONTEXT.md / REQUIREMENTS.md):** A calm, study-focused Bible
reading platform. Serious, academic-leaning, impartial (multiple interpretation
lines). Not a playful consumer app. Not a "clean and modern" generic SaaS — the
reader must feel like a quiet workbench for scripture, opening simple and pulling
depth only on demand (UX-01). Colunas sincronizadas (D-01) + capítulo por coluna
(D-02) + URL canônica `/read/:OSIS` (D-03) + zoom progressivo (UX-01) governam a
superfície. Originais com Strong's (DATA-02/04) não têm UI nesta fase — só a
população do pipeline; CRÉDITOS (DATA-05/D-09) tem tela.

**Genre:** editorial (_anti-slop_, reading-first).
**Tone:** calm / restrained / austere — the content (scripture + study text) is the
hero; chrome recedes.
**Primary surface:** `/read/:OSIS` reader with synchronized translation columns.

## Spacing Scale

Declared values (8-pt multiples):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap, superscript gap, inline padding inside control |
| sm | 8px | Compact element spacing (icon pairs, column-tab gaps) |
| md | 16px | Default spacing; inner cell padding for verse rows |
| lg | 24px | Section padding; column panel padding; tool header gap |
| xl | 32px | Column gutter, nav/header inner padding |
| 2xl | 48px | Major section breaks; phase-gate separators |
| 3xl | 64px | Page-level outer spacing (reader max-width breathing room) |

**Exceptions:**
- Touch targets: icon-only controls (add/remove column, toggle nav) ship at
  `min-height: 48px; min-width: 40px` (responsive-design 44px floor; Hallmark
  interactive-control end-of). Column add controls and sync-tabs must be ≥44×44.
- Reader column measure is set by content, not spacing tokens: 40–46ch per
  chapter column (see Reader column below), wider than a paragraph measure but
  correct for per-column full-chapter rendering.

## Typography

Two families (pairing, per anti-slop discipline):
- **UI / system:** a geometric sans (e.g. `Inter`) — labels, nav, controls, tags.
- **Scripture display:** a high-legibility serif (e.g. `Source Serif 4` /
  `Libre Caslon` pairing for the chapter body) — the actual verse text. The serif
  is reserved for scripture; it is NOT the UI font and MUST NOT be used for
  control labels.

| Role | Size | Weight | Line Height | Family |
|------|------|--------|-------------|--------|
| Display / chapter header | 28px | 600 | 1.2 | sans |
| Heading (book/chapter bar) | 20px | 600 | 1.2 | sans |
| Body (UI: menus, footers, kickers) | 16px | 400 | 1.5 | sans |
| **Scripture text (reader primary)** | **16px** | **400** | **1.15** | **serif** |
| Label / verse number / column tag | 13px | 600 | 1.2 | sans |

| Line height (heading) | 1.2 |
| Line height (body/reading) | 1.5 UI · 1.15 scripture |
| Measure (scripture column) | 40–46ch (serif-readable) |

> Scripture is set at the same 16px as UI body, but distinguished by **family**
> (serif vs sans) plus **measure** (40–46ch) and **line-height** (1.15) — a
> compact, dense reading grid that supports long-session study without an extra
> size step. The 13px label is weight 600 (promoted from 500) so the verse number /
> column tag stays legible and never overpowers the verse text.

## Color

60 / 30 / 10 split, dark-mode-first. The accent is a **focal**, used ONLY to mark
the active verse anchor and the interaction focal (exhaustive list below).

| Role | Value (light) | Value (dark) | Usage |
|------|---------------|--------------|-------|
| Dominant (60%) | `oklch(0.985 0.003 85)` warm paper | `oklch(0.20 0.012 60)` warm ink | Background, base surfaces, app shell |
| Secondary (30%) | `oklch(0.94 0.005 85)` | `oklch(0.26 0.014 60)` | Column panels, nav rail, header, card, active column tab |
| Accent (10%) | `oklch(0.55 0.12 250)` deep oxford | `oklch(0.70 0.13 255)` | Anchor + interaction focal (see list) |
| Destructive | `oklch(0.58 0.20 25)` | `oklch(0.65 0.18 25)` | Error states only (Phase 1 has no destructive action) |
| Neutral (text) | `oklch(0.30 0.01 60)` ink | `oklch(0.88 0.01 60)` | Body text: must hold ≥4.5:1 on both papers |
| Muted (secondary text) | `oklch(0.50 0.01 60)` | `oklch(0.70 0.01 60)` | Verse number, column tag, footnote, secondary labels |

Accent reserved for — **exhaustive, nothing else:**
1. The **active verse anchor highlight** (the single anchored verse row / its
   superscript verse-number marker as a user scrolls or jumps).
2. **Internal reference jump links** (a cross-verse reference the user taps to
   "o âncora move tudo" — D-03).
3. The **focus ring** (`:focus-visible` outline, ≥3:1 against element AND page).
4. The **active column-tab indicator** (which column is the anchor's effective
   delivery — 1px accent underline).

**Not accent:** background tints, gradients, decorative borders; the add-column
button is a secondary/unfilled button; success (green) is unused this phase.

## Copywriting Contract

Portuguese-BR copy (the product is PT-first). Labels short; no two-line
affordances.

| Element | Copy |
|---------|------|
| Primary CTA (surface) | **"Adicionar tradução"** (icon `+` column) — expands synchronized reading to a new column |
| Secondary CTA (column manage) | "Traduções" — opens the column manager; adds/removes columns, max 3 (D-01) |
| Jump reference affordance | verse reference rendered as a jump link (e.g. `Jo 3:16`) with subtle underline — asserts D-03 |
| Empty state (no columns) | heading: **"Nenhuma tradução exibida"** · body: **"Adicione uma tradução de domínio público para começar a ler e comparar."** |
| Loading state | skeleton chapter lines per column (predictable shape → skeleton, not spinner) |
| Error state (load fails) | **"Não foi possível carregar este capítulo."** + retry button · body: "A rede falhou. Verifique sua conexão e tente novamente." |
| Verse not found / out of range | **"Versículo não encontrado nesta tradução."** — inline note, never an error over the whole column |
| Credits / license (Ledger D-09) | "Fontes e licenças" — driven by the ledger table |

**Destructive actions:** NONE this phase. Removing a column is reversible and does
not prompt (reversible, low-stakes action).

## UI Considerations

Element kinds in scope for Phase 1:
- `static-content` — scripture chapter text (core surface).
- `list-collection` — the verse set within a chapter (flowing verse rows).
- `interactive-control` — column add/remove, column tab, translation picker,
  internal reference link.
- `nav` — book/chapter navigation, jump-and-back.
- `media` — none in Phase 1.

Applicable state considerations resolved: 7 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | chapter verses / list-collection | ✅ covered | "Nenhuma tradução exibida" copy when zero columns; a present column never renders a fake "no results". Reader flows pending → loading → error → populated, never a dead blank. |
| loading | chapter reader | ✅ covered | Skeleton chapter-lines (shadcn Skeleton) on `isPending`; no spinner; column tabs keep label + processing affordance. |
| error | reader load | ✅ covered | Full "Não foi possível carregar…" + retry button. |
| populated | reader full chapter | ✅ covered | Multi-column synchronized full chapter (D-02). |
| partial | reader single column | ✅ covered | A single column renders normally; a column whose translation lacks the chapter shows the inline "Versículo não encontrado" note (partial). |
| overflow | column-chapter content | ✅ covered | Each column is its own scroll container; synchronized by anchor; `overflow-x: clip` on `html`/`body`; explicit no viewport horizontal scroll. |
| zero-one-many | reader columns | ✅ covered | Zero → empty copy + add column; one → clean single column; many → 2–3 columns with active-tab sync. |
| long-text | scripture verse | 🧪 backstop | Long verses (Psalm 119) reflow inside the column without truncation. Held-out visual check at 320/375/414 widths → `{ statement: "long verses reflow and wrap inside their column", verification: backstop }`. |
| jump-and-back | interactive-control / nav | 🧪 backstop | Tapping a reference updates the URL and jumps the anchor (D-03); browser back restores prior state. Held-out in-page check at execution. |

## Reader & Layout Contract (Phase-1 core)

The reader is the product's primary screen. Defining it here makes the D-01 /
D-02 / D-03 stack concrete for the planner.

1. **Column layout** (D-01): the surface renders 1–3 translation columns,
   initially one (KJV) with an empty "+"/"Adicionar tradução" header acting as a
   discovery affordance to expand (zoom progressivo).
2. **Whole chapter per column** (D-02). Each column shows a whole chapter inside
   its own scroll container, synchronized by the anchor.
3. **Anchor synchronization** (D-01/D-03): one canonical verse is the anchor. All
   columns scroll so their copy of that verse is aligned; the active verse marker
   is accent. URL `/read/:OSIS` change → anchor moves. "O âncora move tudo".
4. **Chapter-whole sync model**: columns share one verse-index anchor from the
   URL / active verse; on anchor change every column scrolls to align
   (`scroll-into-view` of its anchor row; debounced on programmatic nav, instant
   on a user jump).
5. **Column header**: translation label + version/license tag (KJV-1769, WEB,
   ASV, Almeida — from the ledger), so side-by-side comparison is unambiguous.
6. **Add / remove**: add → next free slot; remove → slot closes; never persists
   (URL is the only state); growth capped at 3 columns (D-01).
7. **Nav**: slim top/left bar for book → chapter → verse; internal references link
   to the same route via `next/link` (D-03), no extra chrome.
8. **Focus**: `:focus-visible` rings on every affordance; never removed.

### Responsive / breakpoints (mobile-first)

Built on Hallmark content-first breakpoints + responsive-design's 375px floor:

| ≤640px (base) | 640–1023px | ≥1024px |
|---|---|---|
| 1 column (anchor default) | 1–2 columns | 1–3 columns (KJV + up to 2 additions) |
| add-column in a shadcn `Sheet` drawing with the translation list | add-column inline tab, condensed | full inline translation picker in the column row |

- `Dialog → Drawer`/`Sheet` on ≤md for the translation picker / column manager
  (responsive-design rule: Drawer over central Dialog on small screens).
- Touch targets ≥44px always; column-tab and add buttons ≥48px on coarse pointers.
- `prefers-color-scheme` dark applies `slate` dark tokens via next-themes; no
  forced-light flash at hydration.

## Motion (restrained)

Motion is a feel-multiplier, not the core (CLAUDE.md stack note). Animate
`transform` / `opacity` only; never layout properties. Use the named easings with
`prefers-reduced-motion: reduce` collapsing spatial motion to a ≤150ms opacity
crossfade. Allowed primitives: synchronized column scroll-into-view (anchor),
column add/remove fade+slide (200ms), skeleton fade-in. No bounce/overshoot on
UI state; no celebratory toasts.
